◆ Capabilities

What makes it production-grade

🛡

Dual authentication

JWT for dashboard users, API keys for server-to-server integrations — bcrypt-hashed, Helmet-protected, rate-limited.

🔁

Idempotent by design

idempotency_key dedupe with a race-condition handler on Postgres unique violations — no double charges.

💰

Settlement engine

2% platform fee, 18% GST and merchant net computed in pure, unit-tested math with drift-free rounding.

🔔

Signed webhooks

Real HTTP delivery signed with HMAC-SHA256. Status tracked, failures retryable via POST /api/webhooks/retry/:id.

📊

Analytics APIs

Success rate, volume, payment-method breakdown and daily summaries powered by PostgreSQL window functions.

🧾

Audit trail

Every state change records old and new values — a complete, traceable history of each payment.

        -H "Content-Type: application/json" \
        -d '{"name":"Shop","email":"u@x.com",
             "password":"s3cret"}'

      # 2 · Create an idempotent payment
      curl -X POST .../api/payments/create \
        -H "x-api-key: pk_..." \
        -d '{"amount":1000,"payment_method":"upi",
             "idempotency_key":"order-001"}'

      # 3 · Capture → settlement calculated
      curl -X POST .../api/payments/capture/<id> \
        -H "x-api-key: pk_..."
